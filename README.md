# TDS Simulator — Mauritius Rental Tax

Calculator for TDS (Tax Deduction at Source) on rental agreements in Mauritius.

- Company vs Individual tenant comparison
- TDS rates: 7.5% (resident) / 10% (non-resident)
- Owner tax impact + recoverable credit

## Production

Live at **https://tds.qontab.com**

## Run locally

```bash
docker compose up -d
```

Then open http://localhost:9300
